# Инструкция по использованию ZVP-GLV атак

## Обзор проекта

Данный проект содержит реализацию **ZVP-GLV атак** (Zero-Value Point attacks с GLV декомпозицией) на эллиптические кривые с быстрыми эндоморфизмами, включая популярную кривую **secp256k1**, используемую в Bitcoin.

### Основные компоненты атак:

- **ZVP (Zero-Value Point)** - атака на нулевые промежуточные значения
- **GLV (Gallant-Lambert-Vanstone)** - использование быстрых эндоморфизмов для ускорения
- **DCP (Dependent Coordinates Problem)** - проблема зависимых координат

## Структура проекта

### Главные файлы для атак:

1. **`experiments.py`** - главный файл для запуска всех экспериментов
2. **`zvp_glv_sac.py`** - ZVP-GLV атака на алгоритм Straus-Shamir с GLV-SAC
3. **`zvp_glv_inter_easy_prec.py`** - ZVP-GLV атака на interleaving алгоритм
4. **`zvp_ltr_signed.py`** - классическая ZVP атака на signed LTR
5. **`dcp.py`** - решение проблемы зависимых координат (DCP)
6. **`utils.py`** - вспомогательные классы и функции
7. **`glv.py`** - функции для работы с GLV кривыми

### Вспомогательные файлы:

- **`tests.py`** - тесты для проверки функций
- **`results_visual.py`** - визуализация результатов
- **`dcp_analysis.ipynb`** - Jupyter notebook для анализа DCP
- **`pari_tools/`** - инструменты PARI/GP для вычислений

## Типы атак и их запуск

### 1. DCP атаки (Dependent Coordinates Problem)

Эти атаки решают проблему зависимых координат для восстановления частей приватного ключа.

#### Запуск DCP атаки через experiments.py:

```python
# Редактируйте experiments.py, раскомментируйте:
if __name__ == "__main__":
    DCP_main()
```

```bash
cd attack
sage experiments.py
```

#### Параметры DCP атаки:

- `zvpparams.target_bits = 4` - количество бит для восстановления (начните с малых значений)
- `n_exp=10` - количество экспериментов
- `t_bounds=(4, 5)` - диапазон целевых бит

### 2. ZVP-GLV атака на Interleaving алгоритм

#### Запуск через experiments.py:

```python
# Раскомментируйте в experiments.py:
if __name__ == "__main__":
    ZVP_main()
    # или
    # interleaving_main()
```

#### Варианты interleaving атак:

- `zvp_glv_interleaving_easy_regular_3` - для окна размера w=3
- `zvp_glv_interleaving_easy_regular_4` - для окна размера w=4  
- `zvp_glv_interleaving_easy_regular_5` - для окна размера w=5

### 3. Классическая ZVP атака

Запуск классической ZVP атаки на signed left-to-right алгоритм:

```python
import zvp_ltr_signed

```

## Как указать свой публичный ключ для тестирования

### Метод 1: Задание приватного ключа (из которого вычисляется публичный)

```python
from sage.all import ZZ
import utils
import glv

# Создание параметров атаки
zvpparams = utils.ZVPparams(bits=256)

# Установка кривой secp256k1
zvpparams.glv.set_secp256k1()

# ВАШ ПРИВАТНЫЙ КЛЮЧ (замените на свой)
your_private_key = 0x1234567890abcdef1234567890abcdef1234567890abcdef1234567890abcdef

# Установка ключа
zvpparams.secrets.k = ZZ(your_private_key)

# GLV декомпозиция: k = k0 + k1*λ (mod n)
decomposition = glv.glv_decompose_simple(
    zvpparams.secrets.k, 
    zvpparams.glv.lam, 
    zvpparams.glv.order
)
zvpparams.secrets.k0 = decomposition[0]
zvpparams.secrets.k1 = decomposition[1]

print(f"Приватный ключ: {hex(your_private_key)}")
print(f"GLV декомпозиция: k0={zvpparams.secrets.k0}, k1={zvpparams.secrets.k1}")

# Вычисление публичного ключа
curve = zvpparams.glv.curve
generator = curve.random_point()  # или используйте стандартную базовую точку
public_key = your_private_key * generator

print(f"Публичный ключ: ({public_key[0]}, {public_key[1]})")
```

### Метод 2: Прямое задание GLV декомпозиции

```python
# Если у вас есть разложение k = k0 + k1*λ
your_k0 = 0x123456789abcdef
your_k1 = 0xfedcba987654321

zvpparams.secrets.k0 = ZZ(your_k0)
zvpparams.secrets.k1 = ZZ(your_k1)

# Восстановление полного ключа
zvpparams.secrets.k = (your_k0 + your_k1 * zvpparams.glv.lam) % zvpparams.glv.order
```

### Метод 3: Задание конкретной точки для тестирования


## Полные примеры запуска

### Пример 1: DCP атака с вашим ключом

```python
#!/usr/bin/env sage

from sage.all import ZZ
import utils
import dcp
import glv

def run_custom_dcp_attack():
    # Параметры атаки
    zvpparams = utils.ZVPparams(bits=256)
    zvpparams.glv.set_secp256k1()
    
    # ВАШ КЛЮЧ
    your_key = 0xdeadbeefcafebabe1234567890abcdef1234567890abcdef1234567890abcdef
    
    # Установка ключа
    zvpparams.secrets.k = ZZ(your_key)
    decomp = glv.glv_decompose_simple(your_key, zvpparams.glv.lam, zvpparams.glv.order)
    zvpparams.secrets.k0, zvpparams.secrets.k1 = decomp[0], decomp[1]
    
    # Настройка атаки
    zvpparams.attack = dcp.glv_dcp_experiment
    zvpparams.target_bits = 4  # начните с малого значения
    
    # Добавление полиномов secp256k1
    secp256k1_polynomials = utils.get_secp256k1_polynomials()
    selection = ["f1", "f11", "f6", "f7", "f9"]
    for name in selection:
        zvpparams.registers.add_tuple(*secp256k1_polynomials[name])
    
    print(f"Атакуемый ключ: {hex(your_key)}")
    print(f"k0: {zvpparams.secrets.k0}")
    print(f"k1: {zvpparams.secrets.k1}")
    
    # Запуск атаки
    zvpparams.do_attack()
    
    print("Результаты атаки:")
    print(zvpparams.results)

if __name__ == "__main__":
    run_custom_dcp_attack()
```

Сохраните как `custom_attack.py` и запустите:
```bash
sage custom_attack.py
```

### Пример 2: Interleaving атака

```python
#!/usr/bin/env sage

import utils
import zvp_glv_inter_easy_prec as inter_easy
import glv
from sage.all import ZZ

def run_interleaving_attack():
    zvpparams = utils.ZVPparams(bits=256)
    zvpparams.glv.set_secp256k1()
    
    # Ваш ключ
    your_key = 0x1122334455667788aabbccddeeff0011
    zvpparams.secrets.k = ZZ(your_key)
    
    # GLV декомпозиция
    decomp = glv.glv_decompose_simple(your_key, zvpparams.glv.lam, zvpparams.glv.order)
    zvpparams.secrets.k0, zvpparams.secrets.k1 = decomp[0], decomp[1]
    
    # Выбор атаки (w=4)
    zvpparams.attack = inter_easy.zvp_glv_interleaving_easy_regular_4
    
    # Использование регистров EFD для secp256k1
    zvpparams.registers = utils.load_efd_secp256k1_registers()["modified:mmadd-2009-bl"]
    
    print(f"Атакуемый ключ: {hex(your_key)}")
    
    # Запуск атаки
    zvpparams.do_attack()
    
    print("Результаты:")
    print(zvpparams.results)

if __name__ == "__main__":
    run_interleaving_attack()
```

## Модификация experiments.py для ваших ключей

Отредактируйте `experiments.py`:

```python
def DCP_main():
    """Set up"""
    zvpparams = ZVPparams(bits=256)
    zvpparams.attack = dcp.glv_dcp_experiment
    zvpparams.target_bits = 4

    # ДОБАВЬТЕ ЗДЕСЬ ВАШ КЛЮЧ
    zvpparams.glv.set_secp256k1()
    your_key = 0x1234567890abcdef  # ваш ключ
    zvpparams.secrets.k = ZZ(your_key)
    
    # GLV декомпозиция
    import glv
    decomp = glv.glv_decompose_simple(your_key, zvpparams.glv.lam, zvpparams.glv.order)
    zvpparams.secrets.k0, zvpparams.secrets.k1 = decomp[0], decomp[1]

    secp256k1_polynomials = utils.get_secp256k1_polynomials()
    selection = ["f1", "f11", "f6", "f7", "f9"]
    for name in selection:
        zvpparams.registers.add_tuple(*secp256k1_polynomials[name])

    # Запуск одного эксперимента вместо цикла
    print(f"Атакуемый ключ: {hex(your_key)}")
    zvpparams.do_attack()
    print("Результат:", zvpparams.results)

if __name__ == "__main__":
    DCP_main()
```

## Интерпретация результатов

Результаты атак содержат следующие поля:

- **`recovered`** - количество восстановленных бит ключа
- **`time_zvp`** - время выполнения атаки в секундах
- **`scalars`** - возможные значения частей ключа
- **`nguesses`** - количество предположений на каждом этапе
- **`point`** - найденная точка (если есть)

Пример результата:
```json
{
    "recovered": 7.2,
    "time_zvp": 48.5,
    "scalars": [[1, 1, 0, 1], [-1, 1, 0, 1]],
    "nguesses": [2, 4, 8, 2]
}
```

## Важные замечания

1. **Начинайте с малых значений**: `target_bits = 4` для первых тестов
2. **Время выполнения**: Атаки могут быть вычислительно затратными
3. **Результаты**: Атаки восстанавливают только префикс ключа, не полный ключ
4. **Безопасность**: Это исследовательские атаки для анализа уязвимостей
