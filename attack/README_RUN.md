# Инструкция по использованию run.py

## Описание

Файл `run.py` - это интерактивный интерфейс для запуска всех типов ZVP-GLV атак из проекта. Он позволяет легко выбрать тип атаки, настроить параметры и запустить эксперименты.

## Быстрый старт

```bash
cd attack
sage run.py
```

## Возможности

### 🎯 Типы атак

1. **DCP Атаки** (Dependent Coordinates Problem)
   - `zvp_attack_experiments_secp256k1` - стандартные GLV DCP эксперименты
   - `glvdcp_all_secp256k1_experiments` - полные GLV DCP эксперименты
   - `dcp_all_secp256k1_interleaving_experiments` - DCP interleaving эксперименты

2. **ZVP-GLV Interleaving Атаки**
   - Поддержка окон размера w=3, 4, 5
   - Использование предвычисленных DCP точек

3. **Классические ZVP Атаки**
   - Signed left-to-right алгоритм
   - Базовый ZVP подход

### ⚙️ Настройки

- **Приватный ключ**: Можно использовать собственный или сгенерировать случайный
- **Параметры атак**: Количество экспериментов, целевые биты, размер окна
- **Полиномы**: Выбор набора полиномов secp256k1

### 📊 Результаты

- Автоматическое сохранение в папку `results/`
- Совместимость с `results_visual.py` для анализа

## Пример использования

1. Запустите: `sage run.py`
2. Выберите тип атаки (например, 1 для DCP)
3. Выберите подтип DCP атаки (например, 1 для GLV DCP)
4. Настройте параметры или используйте значения по умолчанию
5. Выберите, использовать ли собственный ключ
6. Дождитесь завершения атаки

## Значения по умолчанию

- **Количество экспериментов**: 1
- **Целевые биты**: 4-5
- **Размер окна**: 4
- **Полиномы**: f1, f11, f6, f7, f9
- **Приватный ключ**: Случайно сгенерированный
