# Сводка созданных файлов и функций

## 1. Основной боевой скрипт
**`zvp_glv_sac.py`** - Главный скрипт для проведения атаки ZVP-GLV на алгоритм Страуса-Шамира

### Параметры:
- `--pubkey` - Публичный ключ (128 hex символов, обязательно)
- `--bits` - Количество целевых бит (2-32, по умолчанию: 4)
- `--save` - Имя файла для сохранения результатов в JSON
- `--verbose` - Подробный вывод

### Особенности:
- Автоматическая смена рабочей директории в attack/ для корректной работы с pari_tools
- Корректная обработка путей к временным файлам
- Детальный вывод процесса атаки
- Сохранение результатов в JSON формате

## 3. Вспомогательные утилиты
**`pubkey_validator.py`** - Валидатор публичных ключей
- Проверка формата публичного ключа без SageMath
- Валидация точки на кривой secp256k1
- Автономная работа без внешних зависимостей

**`key_checker.py`** - Скрипт для проверки найденных битов
- Загрузка кандидатов из JSON файлов результатов
- Ручной ввод битов для проверки
- Вычисление частичного приватного ключа по формуле GLV
- Расчет диапазона возможных ключей
- Сравнение с известным приватным ключом
- Собственная реализация эллиптической криптографии (без SageMath)

### Параметры key_checker.py:
- `--private-key` - Известный приватный ключ для сравнения
- `--json-file` - JSON файл с результатами атаки
- `--k0-bits` - Биты k0 (ручной ввод)
- `--k1-bits` - Биты k1 (ручной ввод)
- `--verbose` - Подробный вывод

## 4. Демонстрационная версия
**`zvp_glv_sac_demo.py`** - Симуляция атаки без SageMath/PARI
- Имитация процесса атаки
- Генерация примерных результатов
- Демонстрация формата вывода
- Работа без внешних зависимостей

## Структура результатов атаки

Результаты сохраняются в JSON формате:
```json
{
  "pubkey": "04ceb6cbb...",
  "target_bits": 4,
  "timestamp": "2025-01-11 12:34:56",
  "candidates": [
    {
      "k0_bits": [1, -1, 1, 1],
      "k1_bits": [1, 1, -1, -1],
      "confidence": 0.85
    }
  ],
  "statistics": {
    "total_guesses": 16,
    "recovered_bits": 4,
    "success_rate": 0.25
  }
}
```

## Использование

1. **Для реальной атаки** (требует SageMath и PARI/GP):
   ```bash
   sage -python zvp_glv_sac.py --pubkey 04ceb6... --bits 4 --save results.json
   ```

2. **Для демонстрации**:
   ```bash
   python3 zvp_glv_sac_demo.py --pubkey 04ceb6... --bits 4 --save demo_results.json
   ```

3. **Проверка результатов**:
   ```bash
   python3 key_checker.py --private-key deadbeef123... --json-file results.json
   ```

- Скрипты автоматически создают необходимые директории
- Поддержка как реальной атаки, так и демонстрационного режима
- Подробное логирование и отчетность
- Возможность сохранения и анализа результатов
