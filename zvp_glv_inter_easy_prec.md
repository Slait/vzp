# ZVP-GLV Interleaving Easy Precision Attack

## Описание

Этот боевой скрипт реализует атаку **Zero-Value Point (ZVP)** на **GLV-разложение** эллиптических кривых с использованием регулярного интерливинга и легкой точности.

### Что такое ZVP-GLV атака?

**Zero-Value Point (ZVP) атака** - это атака по сторонним каналам, которая использует утечки информации через регистры нулевых значений в алгоритмах multi-scalar multiplication. 

**GLV-разложение** (Gallant-Lambert-Vanstone) - это оптимизация для эллиптических кривых, которая позволяет ускорить скалярное умножение путем разложения скаляра на два меньших числа.

Атака работает следующим образом:
1. Анализирует промежуточные вычисления в алгоритме MSM (Multi-Scalar Multiplication)
2. Детектирует случаи, когда промежуточные точки принимают нулевые значения
3. Использует эту информацию для сужения пространства поиска приватного ключа
4. Снижает энтропию ключа до практически взламываемого уровня

## Использование

### Базовый синтаксис

```bash
python attack_zvp_glv_inter_easy_prec.py --pubkey <HEX_PUBKEY> [ОПЦИИ]
```

### Параметры

#### Обязательные параметры

- `--pubkey <HEX_STRING>` - Публичный ключ (128 hex символов)
  - Формат: 64 символа для X координаты + 64 символа для Y координаты
  - Пример: `79BE667EF9DCBBAC55A06295CE870B07029BFCDB2DCE28D959F2815B16F81798483ADA7726A3C4655DA4FBFC0E1108A8FD17B448A68554199C47D08FFB10D4B8`

#### Опциональные параметры

- `--bits <2-32>` - Количество целевых бит (по умолчанию: 4)
  - Больше бит = более точная атака, но требует больше предвычисленных данных
  - Рекомендуется начинать с 3-4 бит

- `--w <3-10>` - Размер окна для w-NAF представления (по умолчанию: 4)
  - Согласно Figure 6 в научной работе, рекомендуются w = 3, 4, 5
  - Больше w = лучше результат атаки, но требует больше предвычисленных данных

- `--save <filename>` - Сохранить результаты в JSON файл
  - Если не указано, результаты выводятся только на экран

- `--quiet` - Тихий режим (минимум вывода)

- `--verify` - Только проверить корректность публичного ключа

## Устранение неполадок

### Ошибки импорта

```bash
❌ Ошибка импорта: No module named 'sage'
```

**Решение**: Установите SageMath или запускайте через `sage -python`

### Отсутствие предвычисленных данных

```bash
❌ Ошибка: Отсутствуют предвычисленные данные
```

**Решение**: Необходимо выполнить DCP эксперименты для генерации данных:

```bash
# Пример генерации данных для 4 бит
cd attack
sage -python dcp.py --experiment interleaving --bits 4
```

### Неверный публичный ключ

```bash
❌ Публичный ключ не лежит на кривой secp256k1
```

**Решение**: Проверьте формат ключа (128 hex символов) и корректность координат

### Недостаточно памяти

Для больших значений `--bits` может потребоваться много памяти.

**Решение**: 
- Уменьшите значение `--bits`
- Запустите на машине с большим объемом RAM
- Используйте `--quiet` для экономии памяти на вывод

## Расширенное использование

## Техническая документация

### Алгоритм атаки

1. **Инициализация**: Настройка параметров кривой secp256k1 и GLV-разложения
2. **Загрузка данных**: Чтение предвычисленных DCP точек из JSON файлов
3. **ZVP Oracle**: Симуляция multi-scalar multiplication с детекцией нулевых регистров
4. **Фильтрация**: Исключение невозможных комбинаций w-NAF коэффициентов
5. **Вычисление энтропии**: Подсчет оставшихся возможных значений ключа

### Файлы данных

- `interleaving_secp256k1_remapped_3.json` - Данные для 3-битной атаки
- `interleaving_secp256k1_remapped_4.json` - Данные для 4-битной атаки  
- `interleaving_secp256k1_remapped_5.json` - Данные для 5-битной атаки

### Зависимости

- `attack/utils.py` - Базовые классы и утилиты
- `attack/zvp_glv_inter_easy_prec.py` - Основной алгоритм атаки
- `attack/msm.py` - Multi-scalar multiplication и oracle функции
- `attack/glv.py` - GLV-разложение для эллиптических кривых
