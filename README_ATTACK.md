# 🔥 Атака ZVP-GLV на Страуса-трюк Шамира

Реализация атаки из раздела 4.3 научной работы "Decompose and conquer: ZVP attacks on GLV curves"

## 🚀 Быстрый старт

### 1. Проверка публичного ключа
```bash
python3 pubkey_validator.py 04ceb6cbbcdbdf5ef7150682150f4ce2c6f4807b349827dcdbdd1f2efa885a26302b195386bea3f5f002dc033b92cfc2c9e71b586302b09cfe535e1ff290b1b5ac
```

### 2. Запуск атаки (требует SageMath)
```bash
sage -python zvp_glv_sac.py --pubkey 04ceb6cbbcdbdf5ef7150682150f4ce2c6f4807b349827dcdbdd1f2efa885a26302b195386bea3f5f002dc033b92cfc2c9e71b586302b09cfe535e1ff290b1b5ac --bits 4
```

## 📋 Основные параметры

- `--pubkey` - Публичный ключ secp256k1 (130 hex символов, начинается с 04)
- `--bits` - Количество целевых бит (2-32, по умолчанию 4)
- `--save` - Сохранить результаты в JSON файл
- `--verbose` - Подробный вывод

## ⏱️ Время выполнения

- **4 бита**: ~30 секунд
- **6 битов**: ~5 минут
- **8 битов**: ~1 час
